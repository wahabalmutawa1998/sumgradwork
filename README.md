# متابعة المدارس — SUM × TREND

نظام متابعة المدارس والدفعات: المهام، المطبوعات، المسؤولين، المدارس المحتملة، الطلبات، السجل، والإحصائيات.

موقع ثابت — ما يحتاج تنصيب ولا سيرفر ولا خطوة بناء. **للنشر على DigitalOcean راجع [`DEPLOY.md`](DEPLOY.md).**

---

## هيكلة الملفات — وش تعدّل ووش تترك

| الملف | وظيفته | يتبدّل مع التحديثات؟ |
|---|---|---|
| `index.html` | الهيكل اللي يربط الملفات ببعض | نادراً |
| `app.js` | النظام كامل (الكود والبيانات الأولية) | ✅ إي — هذا اللي ينسخ عليه أي إصدار جديد |
| `app.css` | تنسيق النظام الأساسي | ✅ إي |
| `storage.js` | طبقة حفظ البيانات | ❌ **لا تعدّله أبداً** |
| `custom.css` | **تعديلاتك أنت** على الشكل والألوان | ❌ ملفك — ما يلمسه أحد |
| `custom.js` | **إضافاتك أنت** من أكواد | ❌ ملفك — ما يلمسه أحد |
| `assets.js` | الشعارات | نادراً |

**القاعدة:** أي تعديل أو إضافة خاصة فيك حطّها في `custom.css` / `custom.js` بس. لما يجيك إصدار جديد من النظام، تنسخه على `app.js` و `app.css` وخلاص — تعديلاتك وبياناتك ما تنمس.

`custom.css` ينزل بعد `app.css` فأي قاعدة فيه تتغلّب على الأصل، و`custom.js` ينفَّذ بعد النظام كامل.

## ليش التحديث ما يمسح البيانات؟

البيانات (المدارس، المهام، الطلبات، السجل، الأكواد…) **مو داخل الملفات أصلاً** — محفوظة بمتصفح كل جهاز (localStorage) بمفاتيح `st_db_v4` عن طريق `storage.js`. يعني:

- تحديث `app.js` أو `app.css` أو حتى `index.html` → البيانات باقية مثل ما هي.
- اللي يمسح البيانات فعلاً: مسح بيانات المتصفح، التصفح الخفي، أو **تغيير الدومين** (البيانات مربوطة بالدومين).
- عشان كذا: نزّل **نسخة احتياطية** كل فترة من الإعدادات ← البيانات ← نزّل نسخة احتياطية (ملف JSON تقدر تستورده بأي وقت وأي جهاز).

---

## ⚠️ البيانات ما تتشارك بين الأجهزة

الملف يشتغل بالمتصفح بدون سيرفر، فكل جهاز يحفظ نسخته **لحاله**:

- تعدّل أنت من جهازك → التعديل عندك بس
- ريم تفتح نفس اللنك → تشوف البيانات الأصلية، مو تعديلاتك

**للنقل اليدوي:** نزّل نسخة احتياطية (JSON) ودزّها، والثاني يسوي **استورد نسخة**. للمشاركة الحقيقية لازم سيرفر وقاعدة بيانات.

## الدخول

كود الأدمن الافتراضي بهذا الإصدار: `1234` — **غيّره من داخل النظام أول ما تدخل**، وحط كود لكل موظف وفعّله. الموظف يشوف كل شي ويعدّل، بس تعديله يوقف **معلّق** لين توافق عليه من تبويب **الطلبات**.

**الأكواد تنظّم مو تحمي.** تمنع الغلط والعبث العفوي بين الفريق، لكنها مو حاجز أمني حقيقي — أي أحد معه الرابط يشوف النظام.

## التشغيل محلياً

افتح المجلد بأي سيرفر ثابت، مثلاً:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

(فتح `index.html` مباشرة بالمتصفح يشتغل غالباً، بس السيرفر المحلي أضمن.)
