# متابعة المدارس — SUM × TREND

نظام متابعة المدارس والدفعات: المهام، المطبوعات، المسؤولين، المدارس المحتملة، الطلبات، السجل، والإحصائيات.

الملف كامل بذاته — `index.html` واحد ما يحتاج تنصيب ولا سيرفر.

---

## ينزل على GitHub Pages

1. افتح <https://github.com/new> وسوّ ريبو جديد.
2. ارفع `index.html` و `.nojekyll` (زر **Add file → Upload files**).
3. روح **Settings → Pages**، وبخانة **Branch** اختر `main` و `/ (root)`، واضغط **Save**.
4. بعد دقيقتين يطلع لك لنك بالشكل: `https://<اسمك>.github.io/<اسم-الريبو>/`
5. دز اللنك للفريق.

`.nojekyll` مهم — بدونه GitHub أحياناً يتجاهل ملفات معينة.

---

## ⚠️ قبل ما ترفعه — اقرأ هذا

**الريبو العام = بياناتك عامة.** ملف `index.html` جواه أسماء المدارس والفريق و**أكواد الدخول**. أي شخص يفتح اللنك، أو يفتح "عرض مصدر الصفحة"، يشوف كل شي.

خياراتك:

| الخيار | الفريق يوصل؟ | البيانات محمية؟ |
|---|---|---|
| ريبو عام + GitHub Pages | إي، باللنك | ❌ لا — أي أحد يشوفها |
| ريبو خاص (Private) | ينزّلون الملف ويفتحونه بجهازهم | ✅ إي |
| GitHub Pages على ريبو خاص | إي | ✅ إي — بس يبي اشتراك مدفوع |

**الأكواد بهالنظام تنظّم مو تحمي.** تمنع الغلط والعبث العفوي بين الفريق، لكن مو حاجز أمني حقيقي.

---

## ⚠️ البيانات ما تتشارك بين الأجهزة

هذي أهم نقطة. الملف يشتغل بالمتصفح بدون سيرفر، فكل جهاز يحفظ نسخته **لحاله**:

- تعدّل أنت من جهازك → التعديل عندك بس
- ريم تفتح نفس اللنك → تشوف البيانات الأصلية، مو تعديلاتك
- الموافقات والسجل والإحصائيات — كل واحد له نسخته

**للنقل اليدوي:** الإعدادات ← البيانات ← **نزّل نسخة احتياطية** (ملف JSON)، ودزّه لأي أحد، وهو يسوي **استورد نسخة**.

**للمشاركة الحقيقية** لازم سيرفر وقاعدة بيانات — وهذا شغل فريق Summit. النظام هذا نموذج مجرّب تسلّمه لهم بدال مواصفات على ورق.

**البيانات محفوظة بمتصفح الجهاز.** لو مسحت بيانات المتصفح أو فتحت بوضع التصفح الخفي، تروح. نزّل نسخة احتياطية كل فترة.

## أول دخول

الكود الافتراضي للأدمن: **1234** — غيّره على طول من **الإعدادات ← المستخدمون**.

بنفس الصفحة تحط كود لكل موظف وتفعّله. الموظف يشوف كل شي ويعدّل، بس تعديله يوقف **معلّق** لين توافق عليه من تبويب **الطلبات**.

---

## لو بغيت تعدّل الشكل

كل شي بملف واحد: التنسيق داخل `<style>` بالأعلى، والكود داخل آخر `<script>`. التدرج اللوني وباقي الألوان معرّفة بأول التنسيق تحت `:root`.
